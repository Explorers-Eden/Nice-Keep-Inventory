## 📖 Description
**Nice Keep Inventory** tweaks the way the keepinventory gamerule works by only keeping part of your inventory when you die. Keeping only important items like Armor and Tools provides a fair compromise between loosing all your stuff and keeping everything.

In addition to that this data pack also comes with three new enchantments: Safekeep, Deathlock and Gravehold. Details for both are below. A more comprehensive list including enchantments of all our data packs can be found [here](https://enchantments.explorerseden.eu/).
<details>
<summary>Deathlock</summary>
Description: Items lost/Graves created on death can only be obtained by one self~~~~
<br>
Applicable to: Chestplates
<br>
Loot Source: Enchanting Table, Random Loot, Traded Books, Treasure
</details>
<details>
<summary>Gravehold</summary>
Description: Items/Graves dropped on death will stay there for double the time before they disappear
<br>
Applicable to: Chestplates
<br>
Loot Source: Enchanting Table, Random Loot, Traded Books, Treasure
</details>
<details>
<summary>Safekeep</summary>
Description: Keep all items on death at the cost of 33% item durability
<br>
Applicable to: Armor
<br>
Loot Source: Enchanting Table, Random Loot, Traded Books, Treasure
</details>

With **v2.5** forward the data pack also comes with customizable Player Graves and an easy to use in-game config menu which can be accessed by using the `/function keep_inventory`command.

![config_menu](https://cdn.modrinth.com/data/cached_images/6b1691cb950c2d51729bc6b305536ef7aad357f3.png)

**The data pack also functions as the resource pack** for the needed translation keys. *(Mod users automatically have the resources enabled)*

For **PaperMC users**, it is recommended to set the `paper.maxChatCommandInputSize` property to a value between 512 and 1024. More information can be found in the [PaperMC Docs](https://docs.papermc.io/paper/reference/system-properties/#papermaxchatcommandinputsize).
